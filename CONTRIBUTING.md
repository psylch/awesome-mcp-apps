# Contributing

Thanks for your interest in contributing to Awesome MCP Apps!

## Adding an MCP App

Open a pull request adding your app to the appropriate category in `README.md`.

Requirements:
- Must be an **MCP App** (renders interactive UI inside AI chat via the ext-apps protocol), not a regular MCP server
- Must have a public GitHub repo
- Include: name, link, and a one-sentence description
- Place it in the correct category (or suggest a new one)

## Quality Bar

We're looking for apps that are:
- **Functional** — actually works in at least one host (Claude, ChatGPT, VS Code, Goose)
- **Open source** — public repo with code available
- **Distinct** — not a trivial fork of an existing entry

## Format

```markdown
- [name](https://github.com/owner/repo) — One sentence description.
```
